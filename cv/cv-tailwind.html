Impossible de charger cv-data.json

Si vous avez ouvert ce fichier directement (double-clic, file://), le navigateur bloque la lecture du fichier JSON voisin pour des raisons de sécurité.

Solution rapide — lancez un petit serveur local dans le dossier contenant les deux fichiers, puis ouvrez l'adresse indiquée :

python3 -m http.server 8000 puis ouvrez http://localhost:8000/cv-tailwind.html

Ou, si vous utilisez VS Code : clic droit sur cv-tailwind.html → "Open with Live Server".
